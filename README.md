# 신용노트 웹앱 배포 파일 · 1.1.0

`credit-note-web.zip`을 다운로드하고 압축을 푼 뒤, `index.html`이 들어 있는 `credit-note-web` 폴더를 Netlify Drop에 업로드합니다.

- 무한 퀴즈: 교재 6개 PDF의 22개 장에서 직접 작성한 핵심 주제 66개. 기본문항 305개를 순환하며 선지·계산 수치를 변형합니다. 오답 재출제와 이어 풀기를 지원합니다.
- 용어·개념 사전 124개: 정의, 쉬운 설명, 원리·판단 기준, 핵심 확인사항, 예시, 혼동 방지, 출처와 계산 예제.
- 공식 카드와 사전을 **학습** 탭에서 전환합니다. **훈련**, **무한**, **평가**, **기록**을 연결해 사용합니다.
- 기존 공식 카드 36개, 유한 훈련과 1·2·3차 월말평가를 유지합니다. 기존 기록은 같은 사이트에서 보존됩니다.

배포 주소를 iPhone Safari에서 열어 공유 → 홈 화면에 추가를 선택하세요. 첫 실행에서 **오프라인 사용 가능** 표시를 기다립니다. 이미 배포했다면 같은 Netlify 사이트를 업데이트하세요. 다른 주소에서는 저장소가 달라집니다.

개인 학습용 웹앱입니다. 교재의 모든 문장·용어·예제를 수록한 버전은 아닙니다. 3차 평가는 기존 예상 정답 기준입니다. iPhone Safari 실기기 검증은 별도로 필요합니다.

압축 안의 `배포와사용방법.md`에서 자세한 무료 배포·설치·백업 방법을 볼 수 있습니다.
