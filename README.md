# 신용노트 웹앱 배포 파일 · 1.3.0

`credit-note-web.zip`을 다운로드하고 압축을 푼 뒤, `index.html`이 들어 있는 `credit-note-web` 폴더를 Netlify Drop에 업로드합니다. 이미 배포했다면 같은 사이트를 업데이트하세요.

- **교재 연습문제 480문항을 앱 내 텍스트로 구현**: 지문을 읽고 실제 보기 문장을 눌러 답합니다. 문제 내용·보기 순서와 O/X·단답·계산 형식을 유지합니다.
- **공통 지문·계산표 25문항**: 랜덤 순서에서도 자료가 함께 나옵니다. 긴 표는 좌우로 스크롤하고 원래 빈칸을 유지합니다.
- **채점 후 텍스트 해설**: 교재 풀이가 있는 276문항의 해설을 정리하고, 정답만 있는 문항은 그렇게 안내합니다. 원본 이미지는 출처 대조용 선택 기능입니다.
- **문항 순서 랜덤·이어풀기·장별100% 커버리지·숙달률·정답률**과 이전 기록을 유지합니다.
- 기존 무한 퀴즈305개, 사전124개, 공식카드36개와 월말평가도 함께 있습니다.

**평가 → 교재 연습문제**에서 사용합니다. iPhone Safari에서 배포 주소를 열어 공유 → 홈 화면에 추가를 선택하세요. 첫 실행에서 **오프라인 사용 가능** 표시를 기다립니다.

**원자료 누락:** 1권 2장 선택형 3번(PDF 001 상 89페이지)은 제공된 PDF에 보기 문장이 없습니다. 보기를 임의로 만들지 않고 누락을 표시하며 번호 선택·교재 정답·해설 확인을 제공합니다.

2권 3장 계산 2번의 기존 입력 오류를 **2.25%**로 바로잡았습니다. 이전 채점 기록은 소급 변경하지 않습니다. 교재 표기·검산 차이는 앱과 포함된 `교재연습문제와통계.md`에서 확인합니다.

타입 검사·로직/데이터84개·화면36개 테스트를 통과했습니다. iPhone Safari 실기기 검증과 Netlify 실제 사이트 확인은 별도로 필요합니다.
