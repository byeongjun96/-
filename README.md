# 신용노트 웹앱 배포 파일 · 1.2.0

`credit-note-web.zip`을 다운로드하고 압축을 푼 뒤, `index.html`이 들어 있는 `credit-note-web` 폴더를 Netlify Drop에 업로드합니다.

- **교재 장말 연습문제 전체 480문항**: 1권185 / 2권154 / 3권141, 22개 단원. 문제·보기·표·해설을 원문 이미지로 그대로 보존합니다. O/X·단답·계산도 원래 방식으로 풉니다.
- **문항 순서 랜덤**: 출제 순서만 변경하고 문제·보기 순서·원문 번호는 유지합니다. 중간 답안과 순서도 저장하여 이어 풉니다.
- **장별100% 커버리지**: 채점한 서로 다른 문항 / 단원 전체 × 100. 반복은 중복 집계하지 않습니다. 정답률과 연속정답2회 기준 숙달률도 별도로 확인합니다.
- 기존 무한 퀴즈305개, 용어·개념 사전124개, 공식 카드36개와 월말평가를 유지합니다.

**평가** 탭에서 **교재 연습문제**와 **월말평가**를 전환합니다. 오늘 화면에도 교재 원문 학습 바로가기가 있습니다.

배포 주소를 iPhone Safari에서 열어 공유 → 홈 화면에 추가를 선택하세요. 원문132페이지가 추가되었으므로 첫 실행에서 **오프라인 사용 가능** 표시를 기다립니다. 이미 배포했다면 같은 Netlify 사이트를 업데이트해야 기존 기록을 이어갈 수 있습니다.

압축 안의 `배포와사용방법.md`, `교재연습문제와통계.md`에서 설치·백업·집계·출처·검산 안내를 볼 수 있습니다.

개인 학습용 웹앱입니다. 장말 문제는 모두 수록했고 본문 예제는 별도 문항으로 세지 않았습니다. 3차 월말평가는 기존 예상 정답 기준이며 iPhone Safari 실기기 검증은 별도로 필요합니다.
